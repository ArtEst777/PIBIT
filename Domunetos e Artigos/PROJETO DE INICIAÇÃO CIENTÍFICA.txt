1. RESUMO DO PROJETO

Este projeto de iniciação científica visa desenvolver uma luva de realidade virtual de baixo custo com sensoriamento tátil miniaturizado em três pontas dos dedos (polegar, indicador e médio), utilizando a tecnologia eFlesh – um sensor magnético customizável, impresso em 3D, que detecta deformações com precisão submillimétrica (localização com erro de 0,5 mm e força com erro de 0,27 N). O laboratório L-VIS já possui um protótipo funcional de luva VR com sensores flexíveis, mas sem capacidade de detectar forças de contato ou fornecer feedback háptico. Este projeto propõe a miniaturização e integração dos sensores eFlesh na ponta dos dedos selecionados, acoplados a atuadores de vibração (motores ERM), criando uma luva que sente e responde ao toque. Serão desenvolvidas atividades de projeto CAD, fabricação por impressão 3D, eletrônica embarcada, calibração dos sensores e integração com o ambiente Unity 3D. O projeto tem duração prevista de 12 meses e resultará em um protótipo funcional, um conjunto de dados de validação e a documentação completa para replicação, disponibilizada em repositório GitHub. O escopo foi ajustado para 3 dedos para garantir viabilidade dentro da carga horária típica de um bolsista PIBIC.


2. INTRODUÇÃO E CONTEXTUALIZAÇÃO

A interação tátil é fundamental para a imersão em realidade virtual e para o controle remoto de robôs em ambientes perigosos ou remotos. Luvas comerciais com feedback háptico, como as da HaptX ou Meta, custam entre US$ 5.000 e US$ 15.000, inviabilizando seu uso em laboratórios de ensino e pesquisa no Brasil. Essa barreira financeira limita o desenvolvimento de interfaces homem-máquina acessíveis e a formação de recursos humanos na área.

O eFlesh (Pattabiraman et al., 2024) é uma inovação recente que permite fabricar sensores táteis de alta performance com uma impressora 3D doméstica, ímãs de neodímio e uma placa com sensores Hall. O custo estimado por sensor é inferior a US$ 20, tornando a tecnologia acessível para laboratórios com orçamento reduzido. O sensor é baseado em microestruturas de células de corte (cut-cell microstructures), que permitem ajustar a rigidez e a sensibilidade conforme a aplicação (Tozoni et al., 2024).

O Laboratório L-VIS já desenvolveu uma luva de realidade virtual de baixo custo utilizando sensores flexíveis resistivos e uma unidade de medição inercial (MPU-6050), cujo código e documentação estão disponíveis no repositório institucional do laboratório no GitHub (https://github.com/L-VIS/lvis-luva-de-dados). No entanto, a luva atual não possui capacidade de detectar forças de contato nem de fornecer feedback tátil ao usuário. Este projeto propõe um salto tecnológico: a integração de sensores eFlesh miniaturizados na ponta dos dedos polegar, indicador e médio, combinados com atuadores hápticos, para criar uma interface capaz de sentir e responder ao toque. A escolha por 3 dedos (em vez de 5) visa garantir a viabilidade do projeto dentro da carga horária de 20h semanais de um bolsista PIBIC, sem comprometer a relevância científica.


3. JUSTIFICATIVA

3.1. Relevância Científica
- O eFlesh é uma tecnologia recente (2024) e ainda pouco explorada no Brasil. Este projeto contribuirá para a caracterização e validação do sensor em um contexto de luva VR, gerando dados inéditos sobre seu desempenho em aplicações vestíveis.
- A miniaturização do eFlesh para a ponta dos dedos representa um desafio de engenharia que pode gerar contribuições originais em termos de design e integração.
- O escopo reduzido para 3 dedos permite um estudo mais aprofundado da calibração e caracterização de cada sensor, gerando dados de maior qualidade.

3.2. Relevância Social e Educacional
- O desenvolvimento de uma luva de baixo custo com sensoriamento tátil pode ser replicado por outras instituições de ensino, democratizando o acesso à tecnologia de RV.
- A luva tem potencial de aplicação em reabilitação motora (ex.: fisioterapia de mãos), teleoperação (ex.: robôs para tarefas perigosas) e treinamento de habilidades (ex.: cirurgia, manutenção).

3.3. Alinhamento com o L-VIS
- O projeto se insere na linha de pesquisa do laboratório em interfaces homem-máquina e realidade virtual.
- Aproveita a infraestrutura existente (impressora 3D, componentes eletrônicos, experiência da equipe) e amplia as capacidades do laboratório.
- O código e a documentação gerados serão integrados ao repositório GitHub do L-VIS, garantindo continuidade e acesso aberto.


4. OBJETIVOS

4.1. Objetivo Geral
Desenvolver, integrar e validar uma luva de realidade virtual com sensores táteis eFlesh miniaturizados nas pontas dos dedos polegar, indicador e médio, capaz de detectar localização de contato e força normal com precisão compatível com a literatura, e fornecer feedback tátil via motores de vibração.

4.2. Objetivos Específicos
1. Modelar e fabricar três sensores eFlesh miniaturizados para a ponta dos dedos polegar, indicador e médio, utilizando impressão 3D (filamento TPU) e ímãs de neodímio N52.
2. Desenvolver o firmware para leitura simultânea dos 3 sensores (via multiplexador ou barramento I2C) com taxa de amostragem >= 50 Hz.
3. Implementar um modelo de calibração para converter sinais brutos em localização (x, y) e força normal (N) para cada dedo, utilizando redes neurais simples.
4. Integrar motores ERM na luva para fornecer feedback vibratório com intensidade proporcional à força detectada.
5. Validar o sistema comparando a precisão das medições com os dados reportados no artigo original do eFlesh (RMSE localização < 0,5 mm; RMSE força < 0,27 N).
6. Documentar e disponibilizar os arquivos CAD, código-fonte e resultados no repositório GitHub do L-VIS (https://github.com/L-VIS/lvis-luva-de-dados), incluindo um diário de bordo detalhado do desenvolvimento.


5. METODOLOGIA

5.1. Estratégia de Desenvolvimento (Protótipo de Bancada)

Para reduzir variáveis e acelerar o desenvolvimento, o projeto será conduzido em duas fases:

5.1.1. Fase 1 – Protótipo de Bancada (Meses 1–6)
- Os sensores eFlesh serão inicialmente fixados em uma placa rígida (bancada) para testes de calibração, caracterização e validação do firmware.
- Esta abordagem permite isolar problemas de fabricação, calibração e eletrônica antes de integrar os sensores à luva.
- Os motores ERM também serão testados em bancada para avaliar interferência magnética e mecânica.
- Entregável: 3 sensores calibrados e caracterizados, com curvas de força versus sinal validadas.

5.1.2. Fase 2 – Integração na Luva (Meses 7–10)
- Após a validação em bancada, os sensores serão transferidos para a luva.
- Serão realizados ajustes de posicionamento, fixação e isolamento (mecânico e magnético).
- Entregável: Luva com 3 dedos sensorizados e feedback háptico funcional.

5.2. Fabricação dos Sensores eFlesh

5.2.1. Projeto CAD
- Utilização do software Fusion 360 para modelagem dos sensores com geometria adaptada à ponta dos dedos (formato cilíndrico ou cônico).
- Estrutura baseada em microestruturas de células de corte (cut-cell), conforme descrito por Tozoni et al. (2024).
- Parâmetros: tamanho da célula = 8 mm, módulo de Young variando de 0,001 a 0,002 E_f (filamento TPU 95A).
- Inclusão de quatro bolsos (pouches) para encaixe dos ímãs de neodímio (diâmetro 9,525 mm × espessura 3,175 mm).

5.2.2. Impressão 3D
- Impressora: Bambu X1 Carbon (já disponível no L-VIS) com bico de 0,4 mm e filamento TPU 95A.
- Processo: pausa programada na camada anterior ao fechamento dos bolsos. Inserção manual dos ímãs e retomada da impressão para encapsulamento.
- Pós-processamento: inserção da placa com magnetômetro na fenda inferior do sensor.
- Serão impressos 2 sensores extras (total de 5) para contingência em caso de falhas.

5.2.3. Montagem Eletrônica
- Sensor Hall: MLX90393 (ou TLV493D) – sensor de campo magnético triaxial com interface I2C.
- Conexão dos 3 sensores a um multiplexador analógico (CD74HC4067) ou diretamente via I2C com endereçamento configurável.
- Microcontrolador: ESP32 (preferível pela maior capacidade de processamento e comunicação sem fio).

5.3. Firmware e Aquisição de Dados

5.3.1. Leitura dos Sensores
- Taxa de amostragem alvo: >= 50 Hz por sensor.
- Formato de transmissão via serial (UART a 115200 bauds):
  D1x,D1y,D1Fz,D2x,D2y,D2Fz,D3x,D3y,D3Fz\n
  Onde D1 = polegar, D2 = indicador, D3 = médio.
- O firmware será versionado no repositório GitHub do L-VIS, com documentação inline e exemplos de uso.

5.3.2. Calibração
- Coleta de dados com um indenter controlado (suporte com parafuso micrométrico e célula de carga) para gerar curvas de calibração (força vs. sinal).
- Treinamento de uma rede neural simples (MLP com 2 camadas ocultas, 128 neurônios cada) para mapear os 9 sinais (3 sensores × 3 eixos) para forças e localizações.
- Validação com conjunto de dados separado (temporal split, conforme Pattabiraman et al., 2024).

5.4. Feedback Háptico

5.4.1. Atuadores
- Motores ERM (8 mm × 3,4 mm, 3 V, ~60 mA) fixados na camada interna da luva (contato com a pele).
- Escolha justificada: baixo custo, fácil implementação e vibração forte o suficiente para ser percebida na ponta dos dedos.

5.4.2. Plano B para Interferência Magnética
- Risco identificado: o campo magnético do motor ERM pode interferir nas leituras do sensor eFlesh.
- Estratégias de mitigação (em ordem de prioridade):
  1. Isolamento físico: camada de silicone de 2 mm entre o motor e o sensor.
  2. Distanciamento: posicionar os motores na palma da mão (não nos dedos) e transmitir a vibração via estrutura rígida da luva.
  3. Blindagem: envolver o motor com fita de cobre ou mu-metal (custo adicional de ~R$ 50).
  4. Atuador alternativo: se as estratégias acima falharem, substituir os motores ERM por atuadores piezoelétricos (menor interferência magnética, porém maior custo e complexidade).
- Critério de decisão: se a variação do sinal do sensor com o motor ligado for superior a 5% do fundo de escala, a blindagem será aplicada. Se ainda assim não resolver, substitui-se por atuadores piezoelétricos.

5.4.3. Controle
- Acionamento via transistor MOSFET (2N7000) e sinal PWM do microcontrolador.
- Intensidade da vibração proporcional à força normal detectada pelo sensor eFlesh correspondente (0–100%).
- Isolamento: Os sensores eFlesh ficarão em uma capa externa separada da camada dos motores, com uma fina camada de silicone entre elas para evitar interferência magnética e ruído mecânico.

5.5. Diário de Bordo Semanal
- Será mantido um diário de bordo digital (Google Docs ou Notion) com registros semanais de:
  - Atividades realizadas.
  - Problemas encontrados e soluções adotadas.
  - Parâmetros de impressão, calibração e firmware testados.
  - Decisões de projeto e justificativas.
- Este diário servirá como base para o relatório final e para a redação do artigo, e será disponibilizado no repositório GitHub como material de apoio.

5.6. Integração com Software

5.6.1. Unity 3D
- Desenvolvimento de uma cena simples com objetos virtuais que reagem ao toque da luva (ex.: apertar uma esfera e vê-la deformar, tocar em um botão e ativá-lo).
- Conexão via porta serial: leitura dos dados da luva e aplicação ao modelo da mão virtual.

5.6.2. Documentação e Repositório
- Todo o código (firmware + Unity) será versionado no GitHub do L-VIS: https://github.com/L-VIS/lvis-luva-de-dados.
- Arquivos CAD (STL/STEP) e dados de calibração também serão disponibilizados.
- Será criada uma estrutura de pastas organizada (docs/, firmware/, cad/, unity/) para facilitar a replicação por outros pesquisadores.

8. RESULTADOS ESPERADOS

8.1. Resultados Técnicos
- Um protótipo funcional de luva com sensoriamento tátil nas pontas dos dedos polegar, indicador e médio.
- Capacidade de medir força normal com erro < 0,27 N e localizar contato com erro < 0,5 mm (conforme literatura).
- Feedback vibratório proporcional à força de contato, com latência < 50 ms.
- Conjunto de dados de calibração e validação documentado.
- Plano de mitigação de interferência magnética validado experimentalmente.
